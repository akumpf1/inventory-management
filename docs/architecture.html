Data Flow — User Interaction to Render

Step 1 — User Action

Filter selection in FilterBar.vue

User selects a warehouse, category, time period, or order status from dropdown menus pinned below the header.

Step 2 — Shared State Update

useFilters() composable

Reactive ref() values update: selectedPeriod, selectedLocation, selectedCategory, selectedStatus. All views share the same singleton composable.

Step 3 — Watcher Fires

watch() in active view component

Each view watches the four filter refs. Any change triggers loadData(), setting loading.value = true and calling the API client.

Step 4 — HTTP Request

api.js — Axios GET

Filters are serialised as URLSearchParams. Only non-'all' values are appended. Example: GET /api/orders?warehouse=San+Francisco&month=2025-01

Step 5 — Backend Filtering

FastAPI endpoint — in-memory filter

apply_filters() runs list comprehensions over in-memory globals. filter_by_month() handles both YYYY-MM and Q1–Q4 quarter formats. Pydantic validates the output shape.

Step 6 — JSON Response

FastAPI returns filtered JSON array

Validated Pydantic models are serialised and returned with CORS headers. The frontend Axios promise resolves.

Step 7 — Reactive Update

Component ref updated → computed recalculates

Raw data lands in a ref() (e.g., allOrders). Computed properties (summaries, chart series) automatically recalculate. loading.value = false.

Step 8 — Render

Vue re-renders updated DOM

Tables, KPI cards, SVG charts, and badges update in place. No page reload required.

Filter System

📅 Time Period

Query param: month. Supports a specific month or quarter.

all 2025-01 … 2025-12 Q1-2025 … Q4-2025

🏭 Location / Warehouse

Query param: warehouse. Exact string match in backend.

all San Francisco London Tokyo

📦 Category

Query param: category. Case-insensitive match.

all circuit boards sensors actuators controllers power supplies

📌 Order Status

Query param: status. Only applies to orders & dashboard.

all delivered shipped processing backordered
